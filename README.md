### What I'm Interested In

I'm drawn to the questions underneath modern perception systems — how machines can:

- perceive and represent **3D environments**
- estimate **geometry and camera motion** from images
- **reconstruct scenes** from visual observations
- learn **robust, transferable representations**
- combine **geometric reasoning with deep learning**
- build perception that stays **reliable** under real-world conditions
- move from **research prototypes toward production-ready systems**

Recent work has given me hands-on exposure to research-oriented computer vision and 3D reconstruction — enough to know it's where I want to go deeper.
